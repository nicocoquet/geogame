# GeoGame

Prototype personnel d’un jeu quotidien de géolocalisation sur globe physique.

## V0

Cette première version sert à valider la mécanique centrale :

- globe 3D sans noms ni frontières ;
- navigation tactile et souris ;
- une question de test ;
- placement puis validation d’un repère ;
- révélation de la cible ;
- calcul de la distance orthodromique ;
- score provisoire sur 100.

Le barème, le fond cartographique et l’identité graphique sont encore expérimentaux. Les cinq questions quotidiennes, les contenus documentaires et le partage du résultat viendront après validation de cette interaction de base.
